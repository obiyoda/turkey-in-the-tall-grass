# Turkey in the Tall Grass

Play [Turkey in the Tall Grass](https://obiyoda.github.io/turkey-in-the-tall-grass/).

Find the hidden green apple while dodging hunters and other creatures. Tall grass offers cover, and chests, the magic ring, and campfires offer upgrades.

- **Enter** starts the game.
- **WASD** or **arrow keys** move.
- **Space** hides or emerges in tall grass.
- **E** interacts with nearby objects.
- **F** swings the sword and **G** fires the bow once equipped.
- **R** restarts.

To run locally with Node.js 22.12 or newer, run `npm ci` followed by `npm run dev`. Run `npm run check` to test and build.
